# Student Wallet 

I want to recreate my existing Student Wallet website based on this reference:

https://www.figma.com/make/UjxzQM1nhdQGkub758bglh/Student-Wallet-website?t=0SFVIertK5xR1GuT-1

Please study the reference website and recreate its design as closely as possible.

This is a student personal finance management application.

IMPORTANT DESIGN REQUIREMENTS:

Keep the same Student Wallet branding.

Preserve the existing colors, layout, sidebar, dashboard and navigation.

Include the financial overview, income, expenses, budget management, credit card section, notifications and transaction history.

Support Vietnamese and English.

Make the website responsive for computers and mobile phones.

FUNCTIONAL REQUIREMENTS:

Real user registration and login.

Each user has an independent account.

Display the correct user's name.

Each user has separate income and expense records.

Add, edit and delete transactions.

Save data permanently using Supabase.

Automatically calculate balance, income and expenses.

Update dashboard charts and budget progress.

Keep data after logout and login.

Prevent users from accessing other users' data using Supabase Row Level Security.

Do not create a static demo. Build a functional application.

First recreate the existing interface. Then guide me through connecting Supabase and configuring authentication and database security.
